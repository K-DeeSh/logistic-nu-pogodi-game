# 📦 Warehouse Catcher

Браузерная аркадная игра в логистическом сеттинге. Вы — кладовщик, который ловит падающие товары в коробку. Склад в хаосе, WMS ведёт себя непредсказуемо, а товары падают всё быстрее.

## Установка и запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 в браузере.

## Production build

```bash
npm run build
# Статика появится в папке dist/
npm run preview  # локальный превью production-сборки
```

Игра — статический сайт без бэкенда. Можно деплоить на Vercel, Netlify, GitHub Pages и т.д.

## Как играть

**Ноутбук / клавиатура:**
- `←` / `→` или `A` / `D` — двигаться по дорожкам
- `1` / `2` / `3` / `4` — прыгнуть на конкретную дорожку

**Телефон:**
- Кнопки `◀ ▶` внизу экрана
- Кнопки `1 2 3 4` — прямой переход на дорожку
- Свайп по игровому полю

## Механики

| Что падает | При поимке | При пропуске |
|---|---|---|
| 📦 Коробка / 🛍️ Пакет / 📬 Мелкий товар | +5-10 очков, -хаос | +хаос (небольшой) |
| ⭐ VIP заказ | +50 очков | +хаос |
| 🚀 Срочная отгрузка | +30 очков | +хаос |
| ✅ Идеальный товар | +20 очков | ничего |
| 🚫 Без штрихкода / ❌ Ошибка комплектации | −очки, +хаос, −жизнь | ничего (правильно!) |
| 👻 Призрак / 🪤 Приманка / 💀 Фантомный VIP | −очки, +хаос, −жизнь | ничего (правильно!) |

**Комбо:** поимка нормальных и хороших товаров строит комбо-цепочку. Каждый следующий товар даёт бонус к очкам. Поимка плохого/тролля — сброс комбо.

**Хаос-метр:** растёт от ошибок, снижается от правильных действий. При достижении 100% — конец игры.

**Жизни:** 3 жизни. Теряются от поимки плохих объектов.

## Абсурдные события (15 штук)

Каждые ~20-40 секунд случается временное событие (7-9 секунд), которое меняет правила:

1. ⚡ **WMS ушёл в ручной режим** — скорость ↑, очки x2
2. 🔄 **Сканер не в ту сторону** — управление влево/вправо меняется
3. ⭐ **Все товары теперь VIP** — часть хороших — ловушки
4. 📋 **Инвентаризация в разгар смены** — меньше товаров, штраф x2
5. 🌀 **Интеграция жива, но это не точно** — товары мерцают
6. 🧘 **Склад работает по фэншую** — скрытый бонус к комбо
7. 📦 **Система уверена, что всё отгружено** — очки x0.5, но комбо x2
8. 🍕 **Пятничный релиз** — всё быстрее и хаотичнее
9. 🔧 **Ручной режим** — больше товаров, скорость выше
10. 👁️ **VIP клиент смотрит** — VIP-объекты x4 к очкам
11. 💥 **Соседняя команда выкатила обновление** — волна плохих объектов
12. 🔀 **Срочная пересортировка** — мерцание + больше очков
13. 🛒 **Чёрная пятница началась раньше** — максимальная нагрузка
14. 📵 **Маркировка optional** — плохие товары выглядят нормально
15. 🤖 **Алгоритм оптимизировал склад** — скорость x1.5, комбо-множитель x2.5

## Архитектура

```
src/
├── types/
│   └── game.ts          # TypeScript-типы: GameState, FallingItem, ActiveEvent и др.
├── data/
│   ├── items.ts         # Определения всех типов товаров с весами и эффектами
│   └── events.ts        # 15 абсурдных событий с эффектами
├── game/
│   └── gameEngine.ts    # Игровой цикл, spawn, collision, scoring, difficulty scaling
├── components/
│   ├── GameCanvas.tsx   # Canvas-рендеринг игрового поля
│   ├── HUD.tsx          # Score, lives, combo, chaos-метр
│   ├── EventBanner.tsx  # Баннер активного события
│   ├── MobileControls.tsx # Кнопки управления для телефона
│   ├── GameOver.tsx     # Экран конца игры
│   └── StartScreen.tsx  # Стартовый экран
├── utils/
│   └── storage.ts       # localStorage для high score
├── App.tsx              # Главный компонент: game loop, keyboard/touch input
└── main.tsx             # Точка входа
```

**Стек:** React 18 + Vite + TypeScript + HTML5 Canvas (без игровых движков)

**Хранение данных:** только `localStorage` для рекорда, никаких серверов.

## Баланс и сложность

- 0-20 сек: обучение — только обычные товары, медленно
- 20-60 сек: появляются плохие объекты, первые события
- 60-120 сек: controlled chaos — тролли, быстрые события
- 120+ сек: максимальная сложность (capped), проверка реакции
